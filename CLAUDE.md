# Claude project instructions

Before starting, read [RULES.md](RULES.md), [MEMORY.MD](MEMORY.MD), [AGENTS.md](AGENTS.md) and [README.md](README.md). Follow the shared rules throughout the task; this file is an entry point, not a separate set of product requirements.

- Tests, browser validation, lint and type checks are paused until the owner explicitly authorizes them. Builds are separate.
- Keep Laravel 10, system PHP, Filament 3, existing data and the shared studio theme.
- Inspect current code and Git changes before editing. Preserve credentials and user work; never reset the database or publish changes without authorization.
- Record lasting owner decisions in `MEMORY.MD` and architecture changes in `docs/decisions.md`; update the common `RULES.md` rather than duplicating rules here.
